## Publikacja

GitHub Pages: branch `main`, katalog `/ (root)`.

## Kolejne wersje

1. Zapisz nowy podgląd jako kolejny plik, np. `v06.html`, z numerem i datą w notatce nad wiadomością.
2. Umieść tę samą wersję w `index.html`. Główny adres pozostanie bez zmian.
3. Dodaj link do `wersje.html`. Nie nadpisuj wcześniejszych wersji.
4. Zapisz zmiany w `main`; GitHub Pages opublikuje aktualizację.

## Stan projektu

Wersja 05 z 14.10.2026. Wyśrodkowane logo, powitanie i hasło, dopracowane odstępy oraz jasne sekcje. Brak długich myślników. Pełna treść zgodnie z wytycznymi pani doktor, neutralne zwroty do odbiorcy, bez ikon strzałek przy odnośnikach. Dane pacjentki i terminy są fikcyjne; dossier Iwony Gnach jest przykładowe. Wybór pięciu lekarzy pozostaje do wskazania. Linki płatnicze są nieaktywne. To podgląd w przeglądarce, nie gotowy plik Outlook. Test wysyłki pozostaje do wykonania.

Zdjęcia i informacje o lekarzu pochodzą z oficjalnej strony https://unidentunion.pl/ .
Meta `noindex` prosi wyszukiwarki o nieindeksowanie; nie jest zabezpieczeniem dostępu. Podgląd jest publiczny.
