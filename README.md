## Publikacja

GitHub Pages: branch `main`, katalog `/ (root)`.

## Kolejne wersje

1. Zapisz nowy podgląd jako kolejny plik, np. `v08.html`, z numerem i datą w notatce nad wiadomością.
2. Umieść tę samą wersję w `index.html`. Główny adres pozostanie bez zmian.
3. Dodaj link do `wersje.html`. Nie nadpisuj wcześniejszych wersji.
4. Zapisz zmiany w `main`; GitHub Pages opublikuje aktualizację.

## Stan projektu

Wersja 07 z 14.10.2026. Stała opłata za konsultację: 650 zł. Portret lekarza ma kształt prostokąta z płynnymi narożnikami i prowadzi do profilu lekarza. Stopka zawiera ikony oraz aktywne odnośniki do Instagrama, Facebooka i strony WWW. Dodano klikalną kartę rolki z Pauliną z oryginalnym kadrem z podanego materiału. Sekcja wizualizacji zawiera dwa oznaczone miejsca na zdjęcie wyjściowe i wizualizację po leczeniu; oryginalne materiały pozostają do dostarczenia. Zachowano kolejność zdjęć, etapy, bezosobowy ton i sekcję Ilustre. Dane pacjentki i terminy są fikcyjne; dossier Iwony Gnach jest przykładowe. Lista pięciu lekarzy pozostaje do wskazania. Linki płatnicze są nieaktywne. To podgląd w przeglądarce, nie gotowy plik Outlook. Test wysyłki pozostaje do wykonania.

Zdjęcia i informacje o lekarzu pochodzą z oficjalnej strony https://unidentunion.pl/ .
Meta `noindex` prosi wyszukiwarki o nieindeksowanie; nie jest zabezpieczeniem dostępu. Podgląd jest publiczny.
